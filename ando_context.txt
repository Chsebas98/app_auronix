EL PROYECTO

Auronix es una aplicación Flutter de transporte urbano con los siguientes roles:

rolUser → Pasajero/Cliente
rolDriver → Conductor
rolMember → Miembro/Socio
rolGerente → Gerente
rolAdmin → Administrador

Flujo de autenticacion (INMUTABLE)

[Login/Register Form]
→ AuthUnifiedBloc emite AuthUnifiedSuccess(credentials)
→ context.read<SessionBloc>().add(LoginUserEvent(dataUser: credentials))
→ SessionBloc emite SessionAuthenticated
→ GoRouterRefreshBloc notifica al router
→ redirect() en AppRouter navega según role:
rolUser → ClientRoutesPath.home
rolDriver → ConductorRoutesPath.home
\_ → Routes.root

// 1. Datasource (data/datasources/remote/)
class MiRemoteDatasource {
final Dio \_dio;
MiRemoteDatasource(this.\_dio);

Future<MiModel> getData() async {
final response = await \_dio.get('/endpoint');
return MiModel.fromJson(response.data);
}
}

// 2. Repository implementación (data/repositories/)
class MiRepositoryImpl implements MiRepository {
final MiRemoteDatasource \_remote;
MiRepositoryImpl(this.\_remote);

@override
Future<Either<Failure, MiEntity>> getData() async {
try {
final model = await \_remote.getData();
return Right(model.toEntity());
} on DioException catch (e) {
return Left(ServerFailure(message: e.message ?? 'Error de red'));
}
}
}

// 3. UseCase (domain/usecases/)
class ObtenerMiDatoUseCase {
final MiRepository \_repo;
ObtenerMiDatoUseCase(this.\_repo);
Future<Either<Failure, MiEntity>> call() => \_repo.getData();
}

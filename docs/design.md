# Design Characteristics

# Reused Design from Central Memory

## design/modal_dialog.md

# Modal

Ventana superpuesta que captura el foco para una tarea específica (confirmación, formulario corto) sin navegar a otra pantalla.

## design/loading_indicators.md

# Loading

Indicadores de progreso (spinners, barras) para operaciones asíncronas visibles al usuario.

## design/skeleton_loading.md

# Skeleton loading

Reusable placeholder UI shown while content loads, matching the shape of the final layout to reduce perceived latency and layout shift.

## design/search_bar.md

# Buscador

Campo de búsqueda con debounce, resaltado de coincidencias y manejo explícito de estado vacío.

## design/smart_forms.md

# Formularios

Formularios con validación en línea, mensajes de error junto al campo y distinción clara entre obligatorio/opcional.
